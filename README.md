# Güzel Ayakkabı – Online Shoe Store

Güzel Ayakkabı is a PHP and MySQL-based e-commerce website developed as a personal portfolio project.

The project simulates an online shoe store where customers can browse products, select product variations, manage their shopping cart, and place orders. It also includes an administration panel for managing store content.

## Features

### Customer Features
- Browse products by category
- View product details and image galleries
- Select product variations such as size and color
- Add products to the shopping cart
- Register and log in to a customer account
- Manage customer profile information
- Place orders

### Admin Features
- Admin dashboard
- Manage products and categories
- Upload product images
- Manage product variations and stock
- View and manage orders
- Manage store settings

## Technologies Used

- PHP
- MySQL
- PDO
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Installation

1. Install XAMPP or another local PHP and MySQL environment.
2. Clone or download this repository.
3. Place the project folder inside your web server's document root.
4. Create a MySQL database.
5. Import the SQL file from the `database` directory.
6. Update the database connection settings in `functions.php` to match your local environment.
7. Start Apache and MySQL.
8. Open the project in your browser through your local server.

## Project Purpose

This project was created to practice and demonstrate web development skills, including PHP programming, database management, authentication, file uploads, shopping cart functionality, and basic e-commerce workflows.

## Notes

- This is a portfolio and educational project.
- It is designed for local development and demonstration.
- No real payment gateway is integrated.
- The database included in this repository contains sample data, not real customer records.
